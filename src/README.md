RANDOM PASSWORD GENERATOR

PROJECT OVERVIEW:

The Random Password Generator is a Python-based application that generates random passwords according to the length specified by the user.
The program asks the user to enter the required password length and generates a password using a combination of uppercase letters, lowercase letters, and numbers. The random and string modules are used to select characters randomly and create the password.

The project demonstrates the practical use of Python modules, random data generation, string manipulation, user input, loops, and input validation.

OBJECTIVE:

The main objective of this project is to:

Generate random passwords using Python.
Understand the use of Python built-in modules.
Learn how to use the random and string modules.
Practice string manipulation.
Understand the importance of generating unpredictable passwords for security.

FEATURES:

Allows the user to enter the desired password length.
Generates a random password automatically.
Uses uppercase and lowercase letters.
Uses numbers from 0 to 9.
Handles invalid input.
Does not require any external Python packages.

TECHNOLOGIES USED:

Programming Language: Python
Modules: random, string
Editor: Visual Studio Code


HOW THE PROGRAM WORKS:

The program imports the random and string modules.
The user is asked to enter the password length.
The program creates a collection of uppercase letters, lowercase letters, and numbers.
Random characters are selected from this collection.
The selected characters are combined to create the password.
The generated password is displayed on the screen.

CONCLUSION:

The Random Password Generator is a simple Python project that demonstrates library integration, random value generation, and string manipulation. It provides a practical introduction to generating unpredictable password data using Python.
